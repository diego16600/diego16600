### Featured LegalTech Projects

#### 1. ⚖️ PJUD Automated Case & Document Retriever (`consulta-causas`)
* **Problem:** Manual lookup and document downloading across multiple judicial dockets on Chile's *Oficina Judicial Virtual* (`oficinajudicialvirtual.pjud.cl`) is repetitive and time-consuming.
* **Solution:** Built a web application using **Python, Flask, and Selenium** that automates docket queries by ROL and year, enabling batch downloading of judicial resolutions and case files.
* **Impact:** Streamlines case intake and reduces administrative hours for litigation teams.

#### 2. 📚 Instant Statutory Search Engine (`bcn-leychile-search`)
* **Problem:** Navigating long statutory texts during drafting or hearings slows down legal research.
* **Solution:** Developed a lightweight **Python/Flask** web interface integrated with the **Library of Congress of Chile (BCN) LeyChile REST API** for instant article retrieval.

#### 3. 🗂️ Legal Case File Management System (`legal-case-drive`)
* **Problem:** Legal teams need structured, fast access to case evidence, pleadings, and client records.
* **Solution:** Built an end-to-end document management web app using **React, Tailwind CSS, and Firebase**, designed specifically around legal docket organization.

#### 4. 🤖 Legal AI Skills & Agentic Workflows (`legal-ai-skills`)
* **Problem:** Generic LLM prompts often produce inconsistent outputs or miss critical procedural nuances in legal review.
* **Solution:** Curated repository of modular Markdown `SKILL.md` files and structured system prompts for automated admissibility checks, factual timeline extraction, and plain-language client summaries.
